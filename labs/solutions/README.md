# Solutions Folder

Share your lab solutions here!

## How to Submit Your Solution

### 1. Create Your Folder
```bash
mkdir -p solutions/YOUR-GITHUB-USERNAME
```

Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.

### 2. Organize by Lab
```
solutions/YOUR-GITHUB-USERNAME/
├── lab01/
│   ├── nginx-pod.yaml
│   └── notes.md
├── lab02/
│   ├── nginx-replicaset.yaml
│   └── notes.md
└── lab03/
    ├── nginx-deployment.yaml
    └── notes.md
```

### 3. What to Include

**Required:**
- Your YAML files

**Optional but encouraged:**
- `notes.md` - What you learned, challenges faced, tips for others
- Screenshots (if helpful)
- Alternative solutions you tried

### 4. Submit Pull Request
```bash
# Add your files
git add solutions/YOUR-GITHUB-USERNAME/

# Commit
git commit -m "solution(lab##): add my solution"

# Push to your fork
git push origin main
```

Then create a Pull Request on GitHub!
