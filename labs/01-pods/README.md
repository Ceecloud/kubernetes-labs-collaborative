# Lab 01: Creating Your First Pod in Kubernetes

## 🎯 Learning Objectives

By the end of this lab, you will:
- Understand what a Pod is in Kubernetes
- Create Pods using imperative commands
- Create Pods using declarative YAML
- Inspect and debug running Pods
- Delete and manage Pod lifecycle

## ⏱️ Estimated Time
30 minutes

## 📋 Prerequisites

- Kubernetes cluster running (Minikube, Kind, Docker Desktop, or cloud)
- kubectl installed and configured
- Basic terminal/command line knowledge

## 🧪 Lab Environment Setup

Create a dedicated folder for this lab:
```bash
mkdir -p ~/k8s-labs/pods
cd ~/k8s-labs/pods
```
